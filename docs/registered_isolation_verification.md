## 真实场景

注册 `user1 → 小王`、`user2 → 小李`，使用独立 SQLite 目录和 Agent。临时使用 1 完成轮次触发构图，避免重复等待既有 120 秒定时器。

1. user2 发言：“我和小王是朋友。昨天我去了博物馆。”
2. 等待 Graphiti 后台写入完成。
3. user1 查询关系：长期上下文包含“来源用户 user2”的朋友关系，不包含博物馆行程。
4. user2 查询行程：能够召回自己的博物馆经历。
5. 未注册 ID 请求：返回 `__guest__`，长期材料为空，短期仍含共享现场原话。SQLite 的身份字段没有保存该来访原始 ID。
6. user1 尝试撤回 user2 的共同陈述：403 拒绝；对自己隐藏、取消隐藏、提出异议正常。
7. user2 确认来源影响范围后撤回：该共同陈述停止进入 user1 的长期上下文。
8. 原有独立个人记录仍可被其所有者读取，不把“隐藏或撤回一条共同陈述”错误等同于“整个长期数组必须为空”。

图数据库定向测试额外覆盖唯一人物绑定、来源独立性、版本冲突、旧来源重建不复活已撤回陈述、新原话支持重新形成事实，以及旧来源屏蔽后共同材料不返回。

原始报告：`/data1/sunzhixing/Bumi_mem_2_test/runtime/registered_isolation/e2e.json`。报告和测试数据保存在服务器私有实验目录，不纳入代码仓库。

- 原有 `/v1/memory/context` 四字段协议保留，默认 Graphiti 服务启用注册检查。

## 已知限制

共同关系识别仅覆盖明确双人表达，不承诺任意自然语言、多参与者和指代解析。短期对话仍共享。身份由可信 Agent 提供，注册表不替代登录认证。注册与缓存撤销属于单实例；完整用户权限、多实例即时撤销和语音识别未纳入本次实现。
